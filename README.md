# Selenium Java – Basic UI Automation

## Beginner level project made to learn test automation using Java and Selenium.

## Technologies
- Java 17
- Selenium WebDriver
- Maven
- WebDriverManager

## Test object
- Successful login on a demo website: https://www.saucedemo.com

## Test reproduction steps
1. Clone the repository
2. Make sure that Java 17 is installed
3. Run tests using Maven: mvn test
